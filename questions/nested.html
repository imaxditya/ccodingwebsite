Question 1

Write a program to print the following pattern on the screen using nested loops.

11111
11111
11111

Coding

#include stdio.h

void main()
{
    int i, j;

    for(i = 1; i <= 3; i++)
    {
        for(j = 1; j <= 5; j++)
        {
            printf("1");
    }

        printf("\n");
    }
}

Output

11111
11111
11111
